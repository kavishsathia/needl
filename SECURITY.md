# Security policy

Needl handles webhook signing secrets, provider tokens and business events, so we take security reports seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Instead, use GitHub's [private vulnerability reporting](https://github.com/kavishsathia/needl/security/advisories/new) or email kavishwer2301@gmail.com with:

- what the issue is and where it is in the code,
- how to reproduce it,
- what an attacker could do with it.

You'll get a reply within a few days. Once a fix is out, we're happy to credit you.

## Supported versions

Only the latest `main` branch and the deployment at [needl.dev](https://needl.dev) receive fixes.
